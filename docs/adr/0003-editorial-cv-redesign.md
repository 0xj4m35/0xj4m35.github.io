# Editorial CV redesign

We will let the CV move from the earlier compact Geist document treatment toward a warmer editorial one-page CV for this redesign. This supersedes the visual-boundary portion of the local Geist-style CV components decision while preserving the static export, local styling, Geist fonts, semantic CV content, and lightweight dependency model.

The earlier document-style page was maintainable, but it underplayed the senior-engineering signal and buried Minswap's impact metrics. The editorial direction gives the public CV stronger first-viewport positioning, clearer skills hierarchy, and a flagship Minswap section without adding routes, server behavior, a portrait, or a large component dependency.
